# Síntesis metodológica de las fuentes locales

VizData sintetiza principios, no reproduce texto ni imágenes de los libros. Consultar esta referencia para explicar el fundamento o adaptar el skill a una organización.

## Andy Kirk — Data Visualisation: A Handbook for Data Driven Design, 2nd ed.

Aplicaciones incorporadas:

- proceso de diseño antes de ejecutar;
- formulación del brief, examen de datos e intención editorial;
- selección por relación analítica mediante familias de comparación categórica, jerarquía, relaciones, tiempo y espacio;
- marcas y atributos como base de la codificación;
- capas de representación, interacción, anotación, color y composición;
- evaluación según propósito, audiencia, formato y datos.

VizData amplía esta base hacia matrices operativas, formatos digitales y auditoría automatizada.

## Cole Nussbaumer Knaflic — Storytelling with Data

Aplicaciones incorporadas:

- comenzar por contexto, audiencia y acción;
- elegir una visual efectiva y familiar;
- eliminar clutter;
- dirigir atención con jerarquía y contraste;
- pensar como diseñador;
- usar títulos, anotaciones y secuencia para convertir análisis en comunicación.

VizData conserva la distinción entre exploración y explicación para evitar imponer una historia antes de analizar.

## Steve Wexler, Jeffrey Shaffer y Andy Cotgreave — The Big Book of Dashboards

Aplicaciones incorporadas:

- diseñar dashboards desde escenarios y decisiones reales;
- combinar estado, comparación, tendencia y diagnóstico;
- usar small multiples, referencias y detalle bajo demanda;
- adaptar visuales a métricas, tiempo, ranking, utilización, sentimiento, churn y operación;
- reconocer fallas recurrentes: dashboards sin salida, personalización pobre, rojo/verde, pasteles/donuts y burbujas innecesarias.

VizData convierte estos patrones en arquitecturas diferenciadas para dashboards ejecutivos, operativos, analíticos y personales.

## Lindy Ryan — The Visual Imperative

Aplicaciones incorporadas:

- tratar la visualización como competencia organizacional y cultura de descubrimiento;
- diferenciar visualización explicativa, exploratoria e híbrida;
- diseñar para audiencia, medio, movilidad y objetivos;
- integrar alfabetización visual, ética, gobernanza, revisión y colaboración;
- elegir gráficos según necesidades analíticas y permitir iteración responsable.

VizData incorpora controles de privacidad, trazabilidad, accesibilidad y estados interactivos para extender estos principios a web y apps actuales.
